## Solution

```python
class Solution:
    def checkOverlap(self, radius: int, xCenter: int, yCenter: int, x1: int, y1: int, x2: int, y2: int) -> bool:
        x = max(x1, min(xCenter, x2))
        y = max(y1, min(yCenter, y2))
        d = (x - xCenter) ** 2 + (y - yCenter) ** 2
        return d <= radius ** 2
```
