## Solution

```python
class Solution:
    def maxSumOfSquares(self, num: int, sum: int) -> str:
        if sum > 9 * num:
            return ""
        res = ""
        for i in range(num):
            digit = min(9, sum)
            res += str(digit)
            sum -= digit
        return res
```
