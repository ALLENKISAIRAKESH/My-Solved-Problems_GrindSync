## Solution

```python
class Solution:
    def scoreOfParentheses(self, s: str) -> int:
        d = 0
        r = 0
        for i, c in enumerate(s):
            if c == '(':
                d += 1
            else:
                d -= 1
                if s[i-1] == '(':
                    r += 1 << d
        return r
```
