## Solution

```java
class Solution {
    public long sumAndMultiply(int n) {
        if (n == 0) return 0;

        long x = 0;
        int sum = 0;

        String s = String.valueOf(n);

        for (char c : s.toCharArray()) {
            if (c != '0') {
                int d = c - '0';
                x = x * 10 + d;
                sum += d;
            }
        }

        return x * sum;
    }
}
```
