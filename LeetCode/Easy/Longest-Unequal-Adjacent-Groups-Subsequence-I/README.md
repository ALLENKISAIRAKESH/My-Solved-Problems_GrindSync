## Solution

```java
import java.util.*;

class Solution {
    public List<String> getLongestSubsequence(String[] words, int[] groups) {
        List<String> res = new ArrayList<>();
        for (int i = 0, prev = -1; i < words.length; i++)
            if (groups[i] != prev) {
                res.add(words[i]);
                prev = groups[i];
            }
        return res;
    }
}
```
