## Problem Statement

You are given an integer array nums.

Find the minimum length of a subarray that is not identical to any other subarray in nums.

Return an integer denoting the minimum possible length of such a subarray.

Two subarrays are considered identical if they have the same length and the same elements in corresponding positions.

 
OriginalPython3Example 1:


Input: nums = [3,3,3]

Output: 3

Explanation:


	Subarrays of length 1: [3] → appears 3 times
	Subarrays of length 2: [3, 3] → appears 2 times
	Subarrays of length 3: [3, 3, 3] → appears once


The subarray [3, 3, 3] is unique, so the smallest unique subarray length is 3.

Input: nums = [2,1,2,3,3]

	[2] → appears 2 times

	[3] → appears 2 times

The subarray [1] is unique, so the smallest unique subarray length is 1.

Subarrays of length 2:

class Solution:
    def smallestUniqueSubarray(self, nums: List[int]) -> int:
        n = len(nums)
        vals = {v: i for i, v in enumerate(sorted(set(nums)))}
        arr = [vals[x] for x in nums]
        sa = list(range(n))
        rank = arr[:]
        k = 1
        while k < n:
            sa.sort(key=lambda i: (rank[i], rank[i + k] if i + k < n else -1))
            new_rank = [0] * n
            for j in range(1, n):
                prev, curr = sa[j - 1], sa[j]

                prev_key = (rank[prev], rank[prev + k] if prev + k < n else -1)
                curr_key = (rank[curr], rank[curr + k] if curr + k < n else -1)

                new_rank[curr] = new_rank[prev] + (prev_key != curr_key

            rank = new_rank
            if rank[sa[-1]] == n - 1:
                break

            k *= 2

        # Build inverse suffix array
        pos = [0] * n
        for i in range(n):
            pos[sa[i]] = i

        # Kasai's algorithm: calculate LCP with previous suffix
        lcp = [0] * n
        h = 0

        for i in range(n):
            p = pos[i]
            if p == 0:
                continue

            j = sa[p - 1]
            while i + h < n and j + h < n and arr[i + h] == arr[j + h]:
                h += 1

            lcp[p] = h
            if h:
                h -= 1

        # For each suffix, longest common prefix with any other suffix
        max_lcp = [0] * n

        for p in range(n):
            max_lcp[sa[p]] = max(
                lcp[p],
                lcp[p + 1] if p + 1 < n else 0
            )

        # Minimum length that makes some subarray unique
        ans = n

        for i in range(n):
            length = max_lcp[i] + 1
            if length <= n - i:
                ans = min(ans, length)

        return ans
