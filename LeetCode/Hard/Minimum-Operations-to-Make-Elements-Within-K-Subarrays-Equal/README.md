## Problem Statement

You are given an integer array nums and two integers, x and k. You can perform the following operation any number of times (including zero):


	Increase or decrease any element of nums by 1.


Return the minimum number of operations needed to have at least k non-overlapping subarrays of size exactly x in nums, where all elements within each subarray are equal.

 
Example 1:


Input: nums = [5,-2,1,3,7,3,6,4,-1], x = 3, k = 2

Output: 8

Explanation:


	Use 3 operations to add 3 to nums[1] and use 2 operations to subtract 2 from nums[3]. The resulting array is [5, 1, 1, 1, 7, 3, 6, 4, -1].
	Use 1 operation to add 1 to nums[5] and use 2 operations to subtract 2 from nums[6]. The resulting array is [5, 1, 1, 1, 7, 4, 4, 4, -1].
	Now, all elements within each subarray [1, 1, 1] (from indices 1 to 3) and [4, 4, 4] (from indices 5 to 7) are equal. Since 8 total operations were used, 8 is the output.



Example 2:


Input: nums = [9,-2,-2,-2,1,5], x = 2, k = 2

Output: 3

Explanation:


	Use 3 operations to subtract 3 from nums[4]. The resulting array is [9, -2, -2, -2, -2, 5].
	Now, all elements within each subarray [-2, -2] (from indices 1 to 2) and [-2, -2] (from indices 3 to 4) are equal. Since 3 operations were used, 3 is the output.



 
Constraints:


	2 <= nums.length <= 105
	-106 <= nums[i] <= 106
	2 <= x <= nums.length
	1 <= k <= 15
	2 <= k * x <= nums.length

class Solution:
    def minOperations(self, nums: List[int], x: int, k: int) -> int:
        n = len(nums)
        INF = float('inf')

        left = []
        right = []
        sum_left = 0
        sum_right = 0

        def add(v):
            nonlocal sum_left, sum_right

            if not left or v <= -left[0]:
                heappush(left, -v)
                sum_left += v
            else:
                heappush(right, v)
                sum_right += v

            balance()

        def remove(v):
            nonlocal sum_left, sum_right

            # Lazy deletion using heaps
            if v <= -left[0]:
                sum_left -= v
                delayed_left[v] = delayed_left.get(v, 0) + 1
            else:
                sum_right -= v
                delayed_right[v] = delayed_right.get(v, 0) + 1

            prune()
            balance()

        delayed_left = {}
        delayed_right = {}

        def prune():
            while left and delayed_left.get(-left[0], 0):
                v = -heappop(left)
                delayed_left[v] -= 1

            while right and delayed_right.get(right[0], 0):
                v = heappop(right)
                delayed_right[v] -= 1

        def balance():
            nonlocal sum_left, sum_right

            prune()

            while len(left) > len(right) + 1:
                v = -heappop(left)
                sum_left -= v
                heappush(right, v)
                sum_right += v
                prune()

            while len(left) < len(right):
                v = heappop(right)
                sum_right -= v
                heappush(left, -v)
                sum_left += v
                prune()

        costs = [0] * (n - x + 1)

        for i in range(n):
            add(nums[i])

            if i >= x:
                remove(nums[i - x])

            if i >= x - 1:
                prune()
                median = -left[0]
                costs[i - x + 1] = (
                    median * len(left) - sum_left
                    + sum_right - median * len(right)
                )

        # DP
        prev = [0] * (n + 1)

        for j in range(1, k + 1):
            curr = [INF] * (n + 1)

            for i in range(1, n + 1):
                curr[i] = curr[i - 1]

                if i >= x:
                    curr[i] = min(
                        curr[i],
                        prev[i - x] + costs[i - x]
                    )

            prev = curr

        return prev[n]
